# F2F Bank - E2E-автотесты

E2E-автотесты написаны на TypeScript и Playwright для веб-приложения F2F Bank.
Они покрывают сценарии регистрации, авторизации, работу сессии, пополнение баланса и переводы по номеру телефона.

## Запуск

1. Запустить приложение:
   ```bash
   docker compose up -d --build
   ```
   Приложение откроется на http://localhost

2. Установить зависимости и браузер:
   ```bash
   npm install
   npx playwright install chromium
   ```

3. Запустить тесты:
   ```bash
   npx playwright test
   ```

4. Открыть HTML-отчёт:
   ```bash
   npx playwright show-report
   ```

## Описание сценариев для покрытия

| Тест | Сценарий | Приоритет |
|---|---|---|
| auth-1 | Регистрация нового пользователя, последующий вход и проверка отображения имени, фамилии и email в профиле | Critical |
| auth-2 | Попытка входа существующего пользователя с неверным паролем и проверка отсутствия доступа к профилю | Critical |
| auth-3 | Попытка повторной регистрации с уже занятым email | Critical |
| session-1 | Выход из аккаунта и последующая попытка открыть Profile и Transactions без повторной авторизации | High |
| session-2 | Проверка отображения баланса существующего пользователя сразу после авторизации без обновления страницы | High |
| session-3 | Выход из одного аккаунта и вход в другой без обновления страницы с проверкой профиля, истории операций и баланса нового пользователя | Critical |
| dep-1 | Пополнение баланса на положительную сумму с проверкой изменения баланса, создания транзакции и сохранения данных после обновления страницы | Critical |
| dep-2 | Попытка пополнения баланса на 0 и отрицательную сумму с проверкой отсутствия изменений баланса и истории операций | High |
| transfer-1 | Перевод суммы в пределах баланса с проверкой списания средств, создания транзакции и сохранения данных после обновления страницы | Critical |
| transfer-2 | Попытка перевода суммы, превышающей текущий баланс, с проверкой отсутствия списания и новой транзакции | High |
| transfer-3 | Попытка перевода на номер без `+`, с количеством цифр меньше 10 и больше 15 с проверкой отклонения операции | High |
| transfer-4 | Попытка перевода суммы 0 и отрицательной суммы с проверкой отсутствия списания и новой транзакции | High |

## Результаты прогона

Из 16 тестов 12 проходят, 4 падают из-за багов в приложении.
1. В **session-2** после входа баланс показывается как 0, корректная сумма появляется только если обновить страницу.
2. В **session-3** после смены аккаунта не подгружается баланс нового пользователя, профиль и история операций при этом правильные.
3. В **dep-1** и **transfer-1** пополнение и перевод проходят, баланс меняется верно, но в истории операций перепутаны две колонки: в «Operation Type» написано `completed`, а в «Operation Status» - `deposit` или `withdrawal`.

Более подробное описание дефектов в `NOTES.md`

## Найденные баги

| № | Название | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | После входа не отображается сохраненный баланс пользователя | Сразу после успешной авторизации отображается актуальный сохранённый баланс пользователя | После входа отображается 0. Корректная сумма появляется только после обновления страницы |
| 2 | После смены аккаунта баланс не соответствует текущему пользователю | После выхода из одного аккаунта и входа в другой профиль, история операций и баланс относятся к новому пользователю | Профиль и история операций обновляются, но в балансе отображается значение предыдущего аккаунта |
| 3 | В таблице Transactions перепутаны значения Operation Type и Operation Status | Operation Type содержит `deposit` или `withdrawal`, Operation Status содержит `completed` | В Operation Type отображается `completed`, а в Operation Status - `deposit` или `withdrawal` |
| 4 | При пополнении на 0 или отрицательную сумму нет сообщения об ошибке | Невалидное пополнение не выполняется, пользователь получает понятное сообщение о неверной сумме | Пополнение не выполняется и баланс не меняется, но сообщение об ошибке отсутствует |
| 5 | Поле Amount позволяет выбрать отрицательное значение | Поле суммы не позволяет установить значение меньше 0 | С помощью стрелок можно установить отрицательную сумму |
| 6 | Низкая контрастность текста в таблице Transactions | Текст операций хорошо читается на фоне страницы | Текст имеет слишком низкий контраст со светлым фоном, из-за чего данные трудно читать |
| 7 | Некорректно отображается время операции | В истории операций отображается корректное локальное время пользователя | Время отображается со смещением на -3ч, UTC показывается как локальное время |
| 8 | При первом открытии приложения без авторизации появляется ошибка загрузки баланса | Неавторизованный пользователь перенаправляется на страницу входа без ошибок | При первом открытии появляется сообщение «Failed to load balance», хотя пользователь ещё не авторизован |
| 9 | После выхода из профиля и нажатия стрелки «Назад» URL не соответствует отображаемой странице | После выхода защищенная страница остаётся недоступной, а адрес соответствует странице входа `/login` | После выхода из профиля и нажатия кнопки браузера «Назад» отображается форма входа, но в адресной строке остаётся `/profile` |
